# Baan

> Baan (Baan Company N.V.) was a Dutch ERP software vendor founded in 1978 in Barneveld, Netherlands
> by Jan Baan. It is no longer an operating company: acquired by Invensys in 2000, sold to SSA Global
> in 2003, and absorbed into Infor in 2006. The product line continues as Infor LN. Baan publishes no
> first-party API, developer portal, SDK, or specification of its own.

## Status

- Status: acquired / defunct as an independent brand
- Successor product: Infor LN (https://www.infor.com/product-summary/erp/ln/)
- Successor company: Infor Global Solutions
- Legacy domains: baan.com and baan.nl — HTTP only, blanket 301 to the Infor LN product page
- API surface: none. Programmatic access to the Baan lineage is delivered through Infor LN REST APIs
  and the Infor ION API gateway on Infor's developer platform, not by Baan.

## Notable technology (historical)

- Dynamic Enterprise Modeler (DEM) — business-process-driven configuration of the ERP suite
- Baan Tools — the 4GL development environment used to extend and customize the suite
- Component-based ERP architecture, strong in discrete manufacturing and project industries
